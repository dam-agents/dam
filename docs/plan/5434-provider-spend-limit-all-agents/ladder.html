Spend limits: one pattern, four places (v2)

Each place shows the limit it owns, and you change it there. A single line under it lists, muted, the other limits that also count those calls. Click the line, or a provider's whole limit row, to open or close the full list. Every limit has its own icon, the same on every page.

Scenario

1 · Settings › Usage

This page owns the total daily limit: all your agents on every paid provider. The provider limits for all agents stay a small list underneath.

Usage

Set spend limits and see what your agents spend on models.

Choices

  • The "Also counted by" line opens and closes the list; its chevron flips. The text never changes, so nothing jumps.
  • The only limit above the total is the operator's spend ceiling. It appears only when the operator has set one; tick the box at the top to see it.
  • With no ceiling, the line is hidden: nothing else counts these calls.

2 · Settings › Providers

Each provider's limit for all agents is one line: bar, %, Change. Clicking the line opens the limits that also count those calls.

Providers

Choices

  • No label on the line: under a provider in Settings, the limit can only be for all agents. The help tip on "Change" says so.
  • The whole line toggles, and only a chevron shows it. "Show all" is gone.
  • When another limit stops the calls first, the small line under the bar says it ("Total stops first") in the state's colour, even while collapsed.
  • A subscription or Bob provider: no other limit counts it here, so it has no chevron and its line doesn't toggle.

3 · Agent › Usage

This page owns the agent limit: this agent's paid calls on every provider, sub-agents included. Provider limits also count part of those calls, so they show here too, by provider.

Usage · Research bot

What this agent and its sub-agents spend on models.

Choices

  • The list has two groups: On one provider (this agent's limit there, and the limit for all agents there) and Every provider (total daily limit, ceiling).
  • The subscription and Bob show here too. Their own limits are the only ones that count them, and that is now visible here instead of only in a footnote.

4 · Agent › Providers

This page owns this agent's limit on one provider: one line per provider, the same as Settings › Providers.

Choices

  • No "This agent" label: on the agent's page it can only be this agent.
  • Agent limit (agent icon) is the one you set on the agent's Usage page; it counts this agent's paid calls on every provider, so it also counts Anthropic. It stays in the list for dollar providers.
  • An "all agents" limit has the provider icon with a small people mark; this agent's own limit is the plain provider icon.
