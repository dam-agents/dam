What's working

Query batching cuts round-trips and is the biggest win so far. Every high scorer uses it.

Promising but unproven
  • An inverted index scores lower today but scales better as the corpus grows. gen 2
Dead ends
  • Aggressive result caching breaks correctness under concurrent writes. gen 1
  • Tuning constants alone plateaus around 0.75. gen 2
Maintained by an agent after each generation from the whole population. Every Make reads it as static data. Gen 2 read revision r2.
Breadth sits on the Learn to Design edge. Eval scores each candidate; Select is the fan-in. With the synthesizer off it's a blind top-k ranking the conductor runs on opaque scores. With it on, an agent selects and recombines. Either way the conductor never reads a candidate, and the four-step core is untouched.
