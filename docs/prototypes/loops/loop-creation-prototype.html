The Test step. A hard, reproducible gate that returns pass or fail, no judgment. A failing candidate does not stop the loop; it just doesn't move forward.

E
Eval
Judges each candidate

Where the loop learns whether a candidate is good enough. Judges the candidate and returns a verdict (passed stops the loop, continue iterates) plus a score the platform tracks over generations.

C
Curate
Maps Findings into Knowledge
reads findings · writes Knowledge

How the loop remembers what it learned. The one writer of the Knowledge, it reads the raw Findings every step emitted this round and folds them into the curated Knowledge the next Make reads. Knowledge lives on the platform, so no external connection is needed by default.

Image

Prompt
Wrapped by the platform · not editable
Given: an empty sandbox, this round's Findings from every step, and the current Knowledge.
On finish: call curate_done with the updated Knowledge.
