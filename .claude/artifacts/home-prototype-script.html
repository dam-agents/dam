Home Page Prototype — Video Script

Walk through features spatially, top-to-bottom, left-to-right. ~3–4 min recording.

01 Opening & Layout
Full page
  • New two-column activity feed layout — replaces the old section-based home (Ready / Running / Scheduled)
  • Everything lives in a single chronological feed on the left, contextual widgets pinned on the right
  • Greeting + large "Activity" heading anchors the page

→ Move attention to the filter bar

02 Feed Filtering
Top of feed — left column
  • Two-dropdown filter bar: Status (Everything / In progress / Unread / Read / Needs attention) and Time (All time / 24h / 7d / 30d)
  • Stats summary shows "X running · Y to review" at a glance
  • "Clear all" bulk dismisses everything in one click
Demo: toggle Status to "In progress" → only active cards. Switch to "Needs attention" → only approval cards. Reset to "Everything".

→ Scroll down into the feed cards

03 Active Session Cards
Feed — left column
  • Live sessions show animated working dots, elapsed duration, and agent name
  • Experiment cards include a stats pill (e.g. "24 runs · 2 live")
  • Scheduled sessions are marked with the clock icon
  • Click any card → navigates directly to that agent's session
Demo: click an active card to show navigation.
04 Finished Session Cards
Feed — left column
  • Unread blue dot indicator for sessions you haven't visited
  • Artifact button inline on the card — click opens the artifact preview modal (same as production: renders HTML/Markdown/PDF in sandboxed iframe)
  • Experiment cards show result stats (e.g. "120 runs · best 0.87")
  • Hover reveals a "Dismiss" button on every card
  • Dismiss animates: fade + scale, then height collapse
  • Click the card body → navigates to the session
Demo: hover to show Dismiss, click artifact button to open preview modal, dismiss a card to show animation.
05 Approval Cards (Needs Attention)
Feed — left column (inline, not a separate section)
  • Network and tool approval requests appear inline in the feed with amber indicator
  • Full action set: Allow, Allow permanently, Allow all of host, Deny, Deny permanently
  • After actioning, card transforms into its full resolved state — shows what action was taken (e.g. "Allowed permanently") with checkmark, instead of disappearing
  • Denied actions show in red, allowed in muted
  • Hoverable dismiss on both pending AND resolved approval cards
  • Settings button on resolved cards links to network/tool settings
Demo: Allow a request → card transforms to resolved state. Hover → Dismiss button appears. Dismiss → card animates out.
06 Pagination
Bottom of feed — left column
  • Feed is paginated (10 items per page) — avoids layout jumps from infinite scroll
  • Previous / Next buttons with page counter
  • Changing page scrolls to top automatically
Demo: click Next → page scrolls to top showing the next batch.

→ Move to the right sidebar

07 Sidebar — Compute Resources
Right column — top widget
  • Live agent list with CPU/memory usage bars
  • Running vs stopped state indicators (green dot vs grey)
  • Total resource summary at top
  • Aligned flush with the first feed card
08 Sidebar — Spend
Right column — middle widget
  • Period toggle (1d / 1w / 1m / 1y) with consistent styling
  • Total spend as large number, per-agent breakdown bars below
  • Updates live as you switch periods
Demo: click through the period tabs to show spend changing.
09 Sidebar — Schedules
Right column — bottom widget
  • Top 5 schedules listed with cadence and next-run time
  • Toggle switches actually work — enable/disable schedules inline without opening a form
  • "See all" opens a full list modal with the same toggles
  • Click a schedule → opens pre-filled edit form
  • "New" button → opens create schedule form with agent picker
Demo: toggle a schedule off (goes dim), click "See all" to show full list, toggle one there too.

→ Navigate away from home to show the floating pill

10 Floating Approvals Pill
Bottom-right corner — all pages except home
  • Persistent badge in the bottom-right showing pending approval count
  • Only appears when there are approvals needing attention — hides at zero
  • Click to expand into a mini panel with full approval cards (same actions as feed)
  • Resolved state transforms in-place (same full card pattern)
  • Hoverable dismiss on pending and resolved cards
  • Lets you handle approvals without leaving your current context
Demo: navigate to an agent page, show the pill, expand it, approve one → transforms to resolved. Dismiss → collapses. When all dismissed → pill disappears.

→ Navigate to the Components page

11 Components Page (for devs)
/compare route
  • All card variations rendered side-by-side as a component reference
  • Active cards: coding agent, experiment (with stats pill), scheduled
  • Finished cards: plain, with artifact, with experiment stats, scheduled variants
  • Approval cards: network request, tool request, and all resolved states (allowed, denied, permanently)
  • Sidebar widgets: Compute, Spend, Schedules — each in their final form
  • Devs can inspect every state without needing to trigger it in the prototype
Demo: scroll through the components page showing the variety of card states and sidebar widgets.
